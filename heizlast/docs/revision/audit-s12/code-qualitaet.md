## 3. Neue Befunde im Neubau
1. **MITTEL** — Build-Gate hängt an `e2e/`-Typen. Fundort: `heizlast/tsconfig.json` `include: ["src","tests","data","vite.config.ts","playwright.config.ts","e2e"]`, `package.json` `build = tsc --noEmit -p tsconfig.json && vite build`, Root-Build ruft das auf. Beobachtung: Mit der heute von einem anderen Prüfer angelegten, ungetrackten `e2e/abnahme.spec.ts` bricht `npm run build` ab (2× TS2345 `selectOption({ label: RegExp })`, Z. 171/198), obwohl `src/` fehlerfrei ist; ohne diese Datei 0 Fehler (geprüft). Ein Typfehler in einem Playwright-Spec würde damit den Cloudflare-Pages-Deploy der ganzen Website (inkl. Astro) stoppen. Vorschlag: eigenes `tsconfig.e2e.json` (Playwright) und im Build-Script nur `src`/`data`/`tests` prüfen; `e2e` weiter im `lint`. (Die fremde Datei selbst ist kein Repo-Befund.)
2. **MITTEL** — Schallfilter lässt Geräte ohne Schallwert passieren (DATA-04-Rest). Fundort: `src/kern/geraet.ts:212`; `GeraetTreffer` (Z. 47–58) ohne Schallfeld; `src/ui/seiten/Waermepumpe.tsx:47` (Feld «Schall nachts max.»). Beleg: `tests/audit-s12/code-qualitaet/probe-schall.ts` — Filter ≤ 30 dB(A) liefert genau die vier Treffer ohne Wert (OE-0007, OE-0010, PA-0002, OE-0008), kein Hinweis; 13 von 41 Heizungsgeräten ohne `schallNachtMaxDb`. Vorschlag: siehe DATA-04; Test ergänzen.
3. **NIEDRIG** — Optionslisten als Zahlen im Kern (DATA-01 in kleiner Form). Fundort: `src/kern/huelle.ts:857` (`[0.25, 0.3, 0.36, 0.4]` als Dicken-Fallback, obwohl `dickenTypischM` je Bauweise in `huelle-epochen.json` existiert) und `:858` (Dämmdicken 0.02…0.30 m). Beleg: eigene Probe «src/kern enthält keine Objekt-/Array-Literale mit ≥ 4 fachlichen Zahlen» (genau diese 2 Treffer). Vorschlag: beide Listen nach `huelle-epochen.json` (`_meta`/`stufen.daemmdickenM`, `dickenTypischM` als Pflicht je Bauweise).
4. **NIEDRIG** — Kern-Regel in der UI dupliziert. Beleg: Code-Lesen. Vorschlag: Zuordnung als Store-Aktion (`bauteileAnlegen(raumId, lage)`) oder im Kern auflösen («eigener Typ gewinnt, wenn Art passt»), State speichert nur generische Art + `auto`.
